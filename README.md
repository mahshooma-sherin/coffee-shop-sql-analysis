Coffee Shop SQL Analysis

This project is a SQL-based analysis of coffee shop sales data. It explores sales, customers, products, and city-wise information to identify useful business insights.

Tools Used: SQL, Excel, and PowerPoint.

Project Files:

coffee_shop_SQL.sql – SQL queries used for the analysis
sales.xlsx – Sales data
customers.xlsx – Customer data
products.xlsx – Product data
city.xlsx – City data
coffee-report.pptx – Project report and presentation

Key Analysis:

Sales performance
Customer analysis
Product performance
City-wise sales
Revenue analysis
Sales trends
Business insights

This project helped me practice SQL querying and data analysis using real-world business data.
